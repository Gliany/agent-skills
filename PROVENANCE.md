## Gateway extraction

The photo decoder is a sanitized extraction of original user-owned gateway code. Its local runtime dependency path was replaced by a normal sharp package import. New synthetic examples, tests and workflow notes accompany it. No SDK, browser internals, application bundle, production policy or private record is redistributed. External dependencies are pinned in the package lockfile with their license metadata; their source and binaries are not vendored. Existing repository licensing remains unchanged.
